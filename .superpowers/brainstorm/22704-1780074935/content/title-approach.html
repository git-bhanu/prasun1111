How should mixed-weight title sections work in TinaCMS?

Each writing title can mix fonts, weights, and styles. Pick the editing model.

Title sections (array in Tina):
text: "How "
font: Roboto Flex · weight: 700 · style: normal · width: 100%
text: "BIG"
font: Roboto Flex · weight: 900 · style: normal · width: 100%
text: " should the logo be?"
font: Roboto Flex · weight: 300 · style: italic · width: 100%
How BIG should the logo be?

A — Sections Array

Each span is a TinaCMS object with text + explicit font/weight/style controls. Full control, works well with Tina's list UI.

Pros

  • Maximum control per span
  • Supports all Roboto Flex axes (width, slant)
  • Explicit — easy to understand

Cons

  • More fields to fill per section
Tina rich text with custom marks:
How [weight-900]BIG[/weight-900] [weight-300]should the logo be?[/weight-300]
Custom marks rendered as inline toolbar buttons in Tina's rich text editor
How BIG should the logo be?

B — Rich Text + Custom Marks

Single Tina rich text field with custom inline marks for weight/style. Editing feels like a word processor.

Pros

  • Familiar editing UX
  • Faster to type

Cons

  • Custom marks are complex to implement
  • Limited axis control (wdth, slnt harder)
