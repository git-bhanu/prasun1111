# Your Project

A cleaned-up Next.js + TinaCMS base with the sample blog and branded starter content removed.

## Local development

```bash
pnpm install
pnpm dev
```

Useful local URLs:

- `http://localhost:3000`
- `http://localhost:3000/admin`
- `http://localhost:4001/altair/`

## What was kept

- App Router setup
- TinaCMS visual editing
- Page blocks and global site settings
- Tailwind, Biome, and TypeScript setup

## What was removed

- Sample blog routes and post schema
- Sample authors, tags, and posts
- Tina-branded starter copy

## Good first edits

- Add files under `content/` for the collections you want to use
- Create or simplify collections in `tina/collection/`
- Remove any unused block components as your project takes shape
